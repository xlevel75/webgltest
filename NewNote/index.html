하늘이미지

내 컴퓨터에서 만든 이미지와 노트를 내 Google Drive에 안전하게 보관하는 데스크톱 앱입니다.

주요 기능

  • 앱에서 만든 이미지와 노트를 사용자의 Google Drive에 저장
  • 앱이 저장한 파일을 다시 불러와 열람·수정
  • 여러 기기에서 같은 Google 계정으로 내 파일 이어서 사용

Google Drive 접근 범위

하늘이미지는 Google의 drive.file 권한만 사용합니다. 이 권한으로는 앱이 직접 만들었거나 사용자가 앱에서 직접 열도록 선택한 파일에만 접근할 수 있으며, Drive에 있는 다른 파일은 볼 수 없습니다.
